What changed and why

The requested name is applied to the browser title, header, footer, accessible home label, guide, FastAPI title, license notice and npm metadata. Downloads use staff2audio-staff-1.mid and staff2audio-staff-1.wav. The launcher announces staff2audio is ready.

The PyInstaller specification is now staff2audio.spec. Build helpers, smoke checks, archive names, CI artifact filters and tagged release titles agree on staff2audio. Current quickstart and build documentation use the new executable names. Existing PRIMA_* browser-test settings remain supported alongside STAFF2AUDIO_*.
