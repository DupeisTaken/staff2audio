Behavior and implementation

Presets count the displayed beat. In 4/4, choosing 120 BPM means quarter-note 120; in 6/8, choosing 60 means dotted-quarter 60, or quarter-note 90 internally. The helper filters exact choices to the supported integer range and adds its endpoints. Unsupported choices are omitted, and the selected number is applied unchanged.

The selector uses the existing manual tempo path for live playback, clocks, MIDI and WAV. It follows manual edits, shows “Custom · N BPM” for other supported values, and retains choices across staves and PDF pages in the current document. “Use suggested” clears the override. New documents and reloads discard it. Both tempo controls disable while no usable staff is selected.

The desktop settings grid has four columns; narrower layouts use two. A native select provides keyboard operation and a visible label, with the beat unit spelled out in its accessible name. The app has one English interface; there are no additional language variants to verify.

Reproduce and review

Run python -m pytest -q, npm test and node --check static/app.js. For browser checks, install the Python development requirements, run npm ci and npx playwright install chromium, then npm run test:browser. The suite starts/stops its own loopback server and generates its own PDF. Playwright is a development dependency; running Prima still needs no Node installation.

The existing application-check CI workflow now runs the Chromium browser suite. Local results above are completed measurements; current hosted CI results are on the pull request.

Issue #9 · Feature PR · Tempo policy and API

Limits

Presets are product convenience choices, not detected printed tempo markings. Existing recognition and engine limits apply. Saved tempos last only for the current document in the open tab. Windows Edge received local visual verification; Chromium is exercised by CI. Safari, Firefox, physical mobile devices and listening quality were not separately evaluated. Browser audio decoding, scheduling and actual WAV bytes were exercised; no subjective sound-quality claim is made. Python emitted one existing Starlette/httpx deprecation warning; all 76 checks passed.
